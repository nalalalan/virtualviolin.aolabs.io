# virtualviolin.aolabs.io

Vite + React + TypeScript MVP browser violin for laptop keyboard and mouse.

## Commands

- `npm run dev`
- `npm run test`
- `npm run lint`
- `npm run build`
- `npm run preview`
- `npm run deploy`

The public build uses relative asset paths so the same `dist/` output can serve `https://virtualviolin.aolabs.io/` and the fallback `https://aolabs.io/virtualviolin/`.
